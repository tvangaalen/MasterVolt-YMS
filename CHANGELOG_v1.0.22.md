# Mastervolt Web App v1.0.22

## Changes

- Removed the fixed **Type:** header from all Storage tiles.
- Storage subtitles now contain only the battery-type and capacity values, for example `MLI 960A`.
- The existing defensive `Unknown` fallback remains when a battery type cannot be read safely.
- Updated the application version, footer, and service-worker cache to v1.0.22.
