# v0.18.7 — Mockup visual redesign

UI-only release based on v0.18.6.

Changes:
- Reworked dashboard colors to the dark charcoal / teal / green visual language of the approved mockup.
- Replaced emoji tile icons with consistent teal inline SVG pictograms.
- Device names are larger and bold.
- Device type (AC/DC/kind), voltage and current now share the headline row where available.
- State/type information is compacted onto the second line.
- Storage voltage/current share the headline row; SoC uses a compact green bar.
- Reduced tile height while retaining all Sources, Storage and Loads entries.
- Existing MasterBus mappings, calculations and controls are unchanged.
- PWA shell cache bumped to `mastervolt-v0.18.7-shell`.
