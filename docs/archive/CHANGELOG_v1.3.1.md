# Mastervolt Web App v1.3.1

## Changes

- Rebuilt the BMS overview as three side-by-side battery columns.
- Shows every BMS measurement as a consistently aligned row within its battery column.
- Lists each individual cell voltage on its own row for quick comparison.
- Keeps connection state, MOS states, balancing, alarms, cycles, and update time visible in the same column.
- Added compact styling for narrow iPhone screens and matching Light UI borders.
- Updated the application version, footer, and service-worker cache to v1.3.1.

## Unchanged

- All three DALY Bluetooth connections remain persistent and refresh concurrently.
- DALY integration remains read-only.
- Existing hardware-validated MasterBus mappings and control sequences are unchanged.
