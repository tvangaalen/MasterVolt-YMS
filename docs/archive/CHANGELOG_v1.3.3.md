# Mastervolt Web App v1.3.3

## BMS page

- Replaced the SOC circles with analog dial gauges and whole-number percentage values.
- Added a `Cell average` row above `Cell spread`.
- Removed the full-width `Cell voltages` section row so all vertical battery-column separators remain continuous.
- Marks the highest cell voltage in each battery with a red dot and the lowest with a blue dot.
- Removed `DALY` from the page heading and removed the persistent-connection information line.
- Replaced browser confirmation and update messages with styled in-app dialogs matching the Dashboard.
- Update-result dialogs include an OK button and close automatically after the configured duration.

## Settings

- Added the persistent `BMS pop-up duration` setting in seconds.
- Default duration is 3 seconds; accepted range is 1–60 seconds.

## Version

- Updated the application version, footer, and service-worker cache to v1.3.3.
