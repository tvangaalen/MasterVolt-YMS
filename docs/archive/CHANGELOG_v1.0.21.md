# Mastervolt Web App v1.0.21

## Changes

- Added a high-discharge warning for the House Battery.
- When House Battery current is less than or equal to -100 A, its Amp and Watt readings blink red.
- The warning does not trigger for positive current, values above -100 A, Start Battery, or Bow Battery.
- Added matching high-contrast warning colours for both Dark and Light UI.
- Updated the application version, footer, and service-worker cache to v1.0.21.
