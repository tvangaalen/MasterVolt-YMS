# Mastervolt Energy v1.7.2

## History charts

- All time labels use an explicit 24-hour clock.
- Generated power, charging current, DC consumption and DC load current show a dashed average line for the visible period and current legend selection.
- Battery voltage charts now use stacked BMS cell-voltage columns.
- Each battery cell-voltage chart shows BMS Max difference as a dashed red line on a right-hand mV axis.
- Server-side BMS chart data now includes cell voltages and cell spread.
