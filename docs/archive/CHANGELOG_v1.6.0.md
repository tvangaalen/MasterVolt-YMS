# Mastervolt Web App v1.6.0

- Implemented all proposed Sources and Loads history charts using retained Dashboard measurements.
- Sources now shows stacked generated power with a total line, charging current per source, Shore frequency, Solar panel voltage and Alternator temperature.
- Loads now shows stacked DC consumption with a total line, current per DC consumer, AC power, AC output frequency and Inverter operating state.
- Extended the persistent browser cache with Dashboard history while retaining the existing BMS chart cache.
- The Update button now incrementally retrieves both BMS and Dashboard measurements since the preceding update.
- All graph time axes now display dates only, without times.
- Updated application and service-worker cache versions to v1.6.0.
