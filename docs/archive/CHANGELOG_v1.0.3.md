# Mastervolt Web App v1.0.3

- Fixed the Shore Power AC-limit input so it has a non-shrinking width suitable for its numeric amp value.
- Moved the compact `AC limit (A)` label below the input field.
- Added a Mastervolt-style progress modal for Motor, Anchor and Marina mode actions.
- The modal displays `Setting Motor mode`, `Setting Anchor mode` or `Setting Marina mode` and closes automatically after three seconds while the requested device sequence continues.
- Updated application/footer version and PWA cache to v1.0.3.

All mode actions, verified device mappings and Engine ECU safety behavior from v1.0.2 remain unchanged.
