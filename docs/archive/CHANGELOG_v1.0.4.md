# Mastervolt Web App v1.0.4

- Reduced the AC-limit input to a compact fixed 18 px height while retaining its usable numeric width.
- Increased the operating-mode progress modal duration from three to six seconds.
- The selected Motor, Anchor or Marina mode button now receives the same green active treatment as enabled tile controls.
- Operating any individual tile ON/OFF control clears the active mode indication, reflecting a manually changed mode state.
- Updated application/footer version and PWA cache to v1.0.4.

All mode sequences, verified device mappings and Engine ECU safety behavior remain unchanged.
