# Mastervolt Web App v1.0.5

- Replaced the AC-limit number control with an iPhone-friendly numeric text input, removing desktop spinner arrows.
- AC limit now accepts only whole numbers from 1 through 16 in both frontend and backend validation.
- Pressing an already-active mode button now shows `Motor/Anchor/Marina mode already active` with an OK button.
- A Storage state-of-charge value of 100 percent is rendered as `100` without the percent sign to prevent overlap with the circle.
- Updated application/footer version and PWA cache to v1.0.5.

All verified device mappings, operating-mode sequences and Engine ECU safety behavior remain unchanged.
