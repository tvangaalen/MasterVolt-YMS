# v0.18.6 — Compact iPhone dashboard UI

This release keeps the existing Sources / Storage / Loads dashboard structure and all v0.18.5 MasterBus mappings and controls.

UI changes only:

- compressed top header and system-status row;
- reduced section padding and spacing;
- compact 45 px device rows;
- smaller icons and typography while retaining all values and device state text;
- compact storage gauges and value columns;
- compact inverter / AC-limit control strip;
- reduced fixed bottom navigation height;
- added desktop-width tuning while preserving the mobile-first layout;
- bumped PWA cache to `mastervolt-v0.18.6-shell`.

No MasterBus field mappings or control semantics were changed.
