# v0.18.3 baseline

This release intentionally resets the working codebase to v0.17.10.

Version numbering continues at v0.18.3.

Therefore the product-picture work introduced in v0.18.0, v0.18.1 and v0.18.2
is NOT present in this release. Functionality and UI otherwise match v0.17.10,
including the Mass Charger raw state 0 = Off fix.

Future changes should use v0.18.3 as the baseline.
