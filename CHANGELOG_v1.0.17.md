# Mastervolt Web App v1.0.17

## Changes

- Added a high-contrast Light UI designed for improved readability in direct sunlight.
- Kept the existing appearance as the default Dark UI.
- Added a compact Light/Dark toggle directly to the right of the clock.
- The selected appearance is stored locally on the device and restored before the page is drawn to avoid a bright/dark flash.
- Added Light-specific styling for cards, readings, controls, mode buttons, navigation, dialogs, warnings, SOC rings, and supporting animations.
- The browser and installed-app theme colour follows the selected UI.
- Updated the application version, footer, and service-worker cache to v1.0.17.
