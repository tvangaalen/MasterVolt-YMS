# Mastervolt Web App v1.4.2

- Rebuilt the Balance page as a compact four-column matrix matching the BMS page.
- Shows one shared label column and one column for each of the three balancers.
- Groups balance, cell and system values into consistent rows.
- Marks the highest cell voltage with a red dot and the lowest with a blue dot per balancer.
- Keeps raw Bluetooth diagnostics available in collapsed sections below the matrix.
- Preserves direct, read-only Bluetooth access to DL-BAL1, DL-BAL2 and DL-BAL3.
